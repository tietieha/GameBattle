# Buff

This directory reserves the shared Buff ownership boundary: instances, duration,
stacking, expiry, periodic triggers, and owners that may be actors, teams, or a
battle. It deliberately contains no invented implementation.

Existing MOBA-specific Buff code is in Example/Moba/Runtime/Buff. Generalizing it
and adding battle-wide or team-wide ownership are future implementation changes,
not outcomes of the directory migration.
